# ☕ POS CAFE – Laravel POS Application

Sistem **Point of Sale (POS)** untuk Cafe berbasis **Laravel**, dibuat untuk mengelola produk, kategori, transaksi, stok, dan laporan penjualan.

---

## ✨ Fitur Utama

### ✅ **Manajemen Produk**

* Tambah, edit, hapus produk
* Input **harga modal (buy)** dan **harga jual (sell)**
* Upload foto produk
* Manajemen stok

### ✅ **Manajemen Kategori Menu**

Kategori default:

* Coffee
* Tea
* Non-Coffee
* Snack
* Dessert
* Main Course

### ✅ **Transaksi POS**

* Tambah ke cart
* Hitung total otomatis
* Cetak struk
* Support diskon per item atau global

### ✅ **Laporan Penjualan**

* Laporan per hari / bulan
* Total revenue, total profit, jumlah transaksi

### ✅ **User & Role**

* Admin
* Kasir

---

## 🛠️ Teknologi yang Digunakan

* **Laravel 10**
* **Bootstrap**
* **MySQL**
* **Eloquent ORM**
* **Livewire**
* **Laragon / XAMPP**
